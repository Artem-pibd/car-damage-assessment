# 🚀 Быстрый старт (Google Cloud Vision + Ручной режим)

## Что нужно для запуска:

Только **Node.js** (скачайте с https://nodejs.org)

**Сайт работает БЕЗ API ключа!** ✅ (в ручном режиме)

## Пошаговая установка:

### Шаг 1: Установка зависимостей Backend

Откройте терминал в папке `backend`:

```bash
cd backend
npm install
```

### Шаг 2: (Опционально) Настройка Google Cloud Vision

Для работы AI по фото с 1000 бесплатными запросами в месяц:

1. Создайте Google Cloud аккаунт:
   - Перейдите на https://console.cloud.google.com
   - Создайте новый проект (или используйте существующий)

2. Включите Vision API:
   - В меню выберите "APIs & Services" → "Library"
   - Найдите "Vision API" и нажмите "Enable"

3. Создайте Service Account:
   - Перейдите в "IAM & Admin" → "Service Accounts"
   - Нажмите "Create Service Account"
   - Введите имя (например, "car-damage-vision")
   - Нажмите "Create and Continue"
   - Выберите роль "Vision API User"
   - Нажмите "Continue" → "Done"

4. Скачайте JSON ключ:
   - Нажмите на созданный Service Account
   - Перейдите на вкладку "Keys"
   - Нажмите "Add Key" → "Create new key"
   - Выберите "JSON" и скачайте файл
   - Переименуйте файл в `service-account-key.json`
   - Переместите файл в папку `backend`

5. Настройте переменную окружения:
   - Создайте файл `.env` в папке `backend`:
```env
GOOGLE_APPLICATION_CREDENTIALS=./service-account-key.json
PORT=5000
```

**Без этого шага сайт будет работать в ручном режиме!**

### Шаг 3: Запуск Backend

```bash
cd backend
npm start
```

Сервер запустится на порту 5000

Вы должны увидеть:
```
Google Cloud Vision client initialized
Server running on port 5000
```

### Шаг 4: Установка зависимостей Frontend

Откройте новый терминал в папке `frontend`:

```bash
cd frontend
npm install
```

### Шаг 5: Запуск Frontend

```bash
cd frontend
npm run dev
```

Откройте http://localhost:3000 в браузере

## Всё! Готово к работе. 🎉

## Как пользоваться:

### 🤖 AI режим (с Google Cloud):
1. Нажмите "AI по фото"
2. Выберите класс автомобиля
3. Загрузите фото повреждённого авто
4. Нажмите "Анализировать фото"
5. AI автоматически определит повреждения
6. При необходимости скорректируйте серьёзность
7. Получите детальную смету

### 📋 Ручной режим (без API ключа):
1. Нажмите "Ручной выбор"
2. Выберите класс автомобиля
3. Отметьте повреждённые детали галочками
4. Укажите серьёзность каждого повреждения
5. Нажмите "Рассчитать стоимость"
6. Получите детальную смету

## Если хотите изменить цены:

Откройте файл `backend/server.js` и измените:
- `partsPricing` - цены на запчасти
- `laborRates` - нормы времени и ставки работ

## Проверка работы:

Проверьте health endpoint:
```bash
curl http://localhost:5000/api/health
```

Ответ должен быть:
```json
{
  "status": "ok",
  "visionConfigured": true
}
```

Если `visionConfigured: false` - сайт работает в ручном режиме.
