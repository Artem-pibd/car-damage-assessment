# 🚗 Оценка повреждений автомобиля (Google Cloud Vision + Ручной режим)

Сайт для оценки повреждений автомобиля после аварии с поддержкой AI-анализа по фото (Google Cloud Vision) и ручного выбора повреждений.

## Возможности

### 🤖 AI режим (по фото) - Google Cloud Vision
- Загрузка фото повреждённого автомобиля
- Автоматическое определение повреждений с помощью Google Cloud Vision API
- **1000 бесплатных запросов в месяц**
- Fallback: работает без ключа с базовой детекцией

### 📋 Ручной режим
- Выбор повреждённых деталей из каталога
- Оценка серьёзности повреждений (лёгкое/среднее/тяжёлое/критическое)
- Учёт класса автомобиля (эконом/средний/премиум/люкс)
- Автоматический расчёт стоимости запчастей и работ
- Детальная смета с разбивкой по позициям
- Примерное время ремонта
- Рекомендации по ремонтопригодности

## Установка и запуск

### 1. Установка зависимостей Backend

```bash
cd backend
npm install
```

### 2. Настройка Google Cloud Vision (опционально)

Для полноценной работы AI режима:

1. Создайте проект на https://console.cloud.google.com
2. Включите Vision API в проекте
3. Создайте Service Account:
   - IAM & Admin → Service Accounts → Create Service Account
   - Выберите роль "Vision API User"
   - Создайте и скачайте JSON ключ
4. Сохраните JSON ключ в папку `backend` как `service-account-key.json`
5. Создайте файл `.env` в папке `backend`:
```env
GOOGLE_APPLICATION_CREDENTIALS=./service-account-key.json
PORT=5000
```

**Без ключа сайт будет работать в ручном режиме!**

### 3. Запуск Backend

```bash
cd backend
npm start
```

Сервер запустится на порту 5000

### 4. Установка зависимостей Frontend

```bash
cd frontend
npm install
```

### 5. Запуск Frontend

```bash
cd frontend
npm run dev
```

Откройте http://localhost:3000 в браузере

## Как это работает

### AI режим:
1. Пользователь загружает фото автомобиля
2. Изображение отправляется в Google Cloud Vision API
3. Vision API определяет объекты на фото (labels)
4. Система маппит обнаруженные объекты на детали авто
5. Автоматически выбираются повреждённые детали
6. Рассчитывается стоимость ремонта

### Ручной режим:
1. Пользователь выбирает класс автомобиля
2. Выбирает повреждённые детали из списка
3. Указывает серьёзность каждого повреждения
4. Нажимает "Рассчитать стоимость"
5. Система рассчитывает стоимость и время

## Каталог запчастей

В базе данных содержатся цены на:
- Бамперы (передний/задний)
- Фары и фонари
- Двери
- Крылья
- Капот и багажник
- Стёкла
- Зеркала
- Радиатор и решётка
- Детали подвески
- Кузовные работы (покраска, вмятины, царапины)
- Колёса и шины

## Цены

Цены в базе данных - средние по рынку РФ:
- Запчасти: от 3,000 ₽ до 80,000 ₽
- Работы: 1,500 ₽/час
- Учитывается класс автомобиля (множитель: эконом x1.0, средний x1.2, премиум x1.5, люкс x2.0)

## Google Cloud Vision API

- **Бесплатно**: 1000 запросов в месяц
- **Платно**: $1.50 за 1000 запросов после бесплатного лимита
- **Модель**: Label Detection (определение объектов на изображении)
- **Без ключа**: сайт работает в ручном режиме
- **Получить ключ**: https://console.cloud.google.com

## Важные замечания

- ⚠️ Оценка является приблизительной и носит информационный характер
- Для точной оценки необходимо обратиться в автосервис
- Цены могут варьироваться в зависимости от региона и марки автомобиля
- AI анализ может не определять все типы повреждений
- Рекомендуется использовать AI режим как вспомогательный инструмент

Чтобы изменить цены на запчасти или работы, отредактируйте файл `backend/server.js`:
- `partsPricing` - цены на запчасти
- `laborRates` - нормы времени и ставки работ
